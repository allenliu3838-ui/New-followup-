30 天试用，怎么跑通

先用模拟病例熟悉流程；真实数据录入须符合所在机构的审批和授权要求。
1
建项目，选病种场景
→ IgAN / MN / LN / CKD 等模板字段自动加载
2
录入 3–5 例模拟病例
→ 练习日期 / BP / Scr / UPCR 等字段；正式必填项由研究方案确定
3
一键导出首版数据包
→ 结构化 CSV + 字段说明 + 示例分析脚本
4
看 QC 报告，补录字段
→ 核心字段完整率可见，缺口清单一目了然
5
生成可汇报版本
→ 复跑，锁定版本，用于汇报 / 多中心合并
立即开始试用 查看完整操作说明
试用成功标准：能稳定导出分析包并完成至少 1 轮 QC → 补录 → 复跑。

为什么选择肾域·科研

为分析复现做好准备
结构化数据、字段说明与示例分析脚本支持研究汇总；复现时需固定数据、脚本和运行环境版本，并核对结果。
先统一规则，再合并数据
按项目、中心与研究编号核对患者和访视归属；合并前检查重复、时间窗、单位和字段定义。
把数据质量变成日常流程
通过 QC → 核查 → 修订 → 复跑逐步改善数据质量。缺失原因、修订依据和导出版本由项目团队共同记录。
合规边界：仅用于随访数据登记与研究汇总，不提供诊断/处方/急救指导；禁止录入姓名/电话/病案号/身份证等个人信息（PII）。
