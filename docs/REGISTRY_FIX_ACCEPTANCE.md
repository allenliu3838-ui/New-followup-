## 数据库与权限边界

- `0032_security_integrity.sql`：临床访问、患者令牌、输入约束、单位与日期、计算值更新、公共对象授权。
- `0033_billing_registration.sql`：试用与计费权威状态、订单和审核、注册资料及同意记录。
- `0034_import_corrections.sql`：幂等批量导入、更正及核心记录变更审计。
- `0035_frozen_exports.sql`：不可直接修改的冻结导出内容及完整性校验。
- `0036_project_members.sql`：项目成员、独立能力检查、临床表 RLS 和相关 RPC。

负责人拥有项目管理和导出权限；录入员可写临床记录并管理随访链接；分析员可读和使用专用导出功能；只读成员可读。一个项目的成员身份不会改变其在自己项目中的权限，也不会赋予他人订阅、订单或项目归属的管理权。阅读授权不能阻止截图或手工复制。

录入员降级或移除时，会原子撤销项目全部有效患者链接，以阻止其通过已复制链接继续访问；操作前明确提示，之后需要重新发放。临床记录的项目和患者归属不可通过直接更新搬移，避免跨项目和权益限制旁路。

历史未知单位保留为待核实，不能凭数值猜测换算。旧快照只含元数据时，不会伪装成已经保存的完整数据副本。冻结导出仍受项目生命周期和保留规则约束，不等于永久备份或不可删除归档。

八条历史数据关联约束按迁移设计先以 NOT VALID 添加，新写入已受约束；已有孤儿记录仍需核查并验证约束。本次没有自动删除旧记录或猜测其归属。
