重点模块说明

GENERAL（通用 / 混合）模块

什么时候用 GENERAL？

  • 病种是 FSGS、ANCA、糖尿病肾病、高血压肾病等
  • 研究对象是"全科患者"（混合病种）
  • 做跨病种对照研究（如 IgAN vs. FSGS）
  • 科室质量改进（QI）项目
  • 尚不确定病种分层，先建库再细分

分析包当前提供什么？

  • eGFR 描述性趋势（成人公式适用性需复核）
  • UPCR 描述性趋势与单位核对，不自动判定缓解
  • 年度访视选取与数值阈值候选，不等于确认终点
  • Table 1 基线特征表
  • QC 报告（缺失 / 单位 / 来源问题）
  • 实际执行步骤说明（英文，研究团队复核后使用）

病种特有化验可录入扩展表；默认脚本仅处理说明中的六张核心表，额外专病统计需单独实现与验证。

多中心协作

多中心合并键设计

🔑 合并键规则

  • 每个中心设置唯一 center_code（如 BJ01 / SH01 / GZ01）
  • 患者研究编号 patient_code 各中心内唯一
  • 分析身份键 = project_id + center_code + patient_code
  • 保留原始记录 ID；先核对字段、单位与编号，冲突会阻止合并

📦 DCC 合并流程

  • 各中心独立录入，后台各自导出分析包
  • DCC 收齐各中心六张 CSV，运行 merge_centers.py 校验合并
  • 确认 MERGE_OK，再用 --data 指向合并目录运行分析
  • 核对输入哈希与人数；合并总体结果不等同各中心子集结果
流程示例（模拟）：3 中心 IgAN 研究（BJ01 / SH01 / GZ01），假设合计 280 例
→ 各中心导出 → DCC 核对与合并 → 描述性分析 → 团队复核；不预设完成时间或研究结果
安全与合规

研究编号 · 权限管理 · 版本核对

🔒 去标识化

  • 研究记录使用 patient_code；不录入姓名、证件号等直接身份信息
  • 身份映射表由各中心本地受控保管
  • 编码后的健康记录仍可能识别个人，须在批准与授权范围内共享

📸 快照可复现

  • 冻结同一次读取的研究数据并生成版本编号
  • 分析包保留 research_data.json 与文件哈希清单
  • 复核须保留相同输入、脚本与依赖环境，并核对运行日志
  • 冻结版本可重新下载；旧元数据记录不能恢复历史内容

⏰ 到期只读

  • 无有效付费权益时，试用到期后停止新增与更正
  • 授权用户查看与导出，不因 7 天宽限期结束而阻断
  • 有效付费项目按实际权益继续录入，不被旧试用日期锁定

操作流程（PI / 研究生视角）

从录入到分析：后台与本地流程

后台操作（/staff）

  • 创建项目：填 center_code + 选模块（IgAN / LN / MN / GENERAL…）
  • 录入基线：patient_code + 入组日期 + Scr + UPCR + 可选病理
  • 发随访链接：生成 token → 发给随访护士，无需登录即可录入
  • 导出分析包：一键 zip，包含去标识化 CSV + 分析脚本

本地分析（研究生）

  • 解压分析包
  • 在包根目录建独立 Python 环境，按 analysis/README.md 安装依赖
  • python analysis/run_analysis.py
  • 成功后打开 analysis/outputs/run-时间/，先核对日志和 QC
  • 看 QC → 更正并重新导出 → 复跑；不能将旧输出当成本次结果

谁应该使用这套系统？

适合 4 类用户

🔬 PI / 科研负责人

  • 需要建立多中心随访数据库
  • 已有研究问题，需要规范数据整理与分析输入
  • 希望数据可复现，经得起审稿人核查

🎓 研究生 / 住院医

  • 毕业论文需要随访数据，但不会写分析脚本
  • 想快速出图出表，省去繁琐 Excel 操作
  • 需要规范的 Methods 段落草稿

🏥 临床协调员 / 护士

  • 负责随访录入，希望通过简短培训掌握日期与单位核对
  • 用手机 / 电脑打开随访链接即可录入
  • 不需要登录，只需点 token 链接

🏛️ 机构 / DCC

  • 管理多中心数据合并与质量控制
  • 需要稳定可复现的分析基础设施
  • 评估机构部署，并核验数据流向、备份与运维边界
常见问题

快速 FAQ

问题回答
可以用于注册临床试验（IND）吗？本系统用于研究登记。具体试验与验证要求须单独评估；私有化部署本身不等于满足 GCP/Part 11。
数据存在哪里？网页托管于阿里云，认证与数据使用 Supabase 云服务。具体区域须核实本登记站连接项目；目前不声明全部数据在境内。
GENERAL 模块没有我需要的字段怎么办？按表结构录入化验、用药等扩展记录；新增统计须另行编写与验证，不能仅加字段就认定已完成分析。
多个课题可以共用一个系统吗？可以；按课题创建项目，以 project_id 与成员授权控制访问。center_code 用于中心标识，不单独承担权限隔离。
随访护士不会用电脑怎么办？授权随访链接可在手机浏览器打开，无需账号；仍须核对研究编号、日期、血压、肌酐和 UPCR 单位。
