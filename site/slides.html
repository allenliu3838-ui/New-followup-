临床研究随访中的常见难题

随访、整理、复核三件事

谁该随访说不清

  • 逾期、失访靠记忆或手工表格
  • 随访结果散在纸质表、表格和聊天记录里
  • 患者不会用手机时只能事后补录

整理数据耗时

  • 多中心靠人工复制粘贴合并
  • 编号、单位口径不一，反复清洗
  • 统计脚本各写各的，难以复核

数据版本说不清

  • 姓名、电话等身份信息混入数据集
  • 边改边分析，不知道用的是哪一版
  • 修改没有原因记录，事后无法追溯

模块说明

GENERAL（通用 / 混合）模块

什么时候用 GENERAL？

  • 局灶节段性肾小球硬化、ANCA 相关血管炎、糖尿病肾病、高血压肾病等
  • 研究对象是混合病种的门诊队列
  • 跨病种对照研究
  • 科室质量改进项目
  • 尚未确定病种分层，先建队列再细分

分析脚本当前提供什么？

  • 描述性基线表（Table 1）与数据质控清单
  • 估算肾小球滤过率（eGFR）与 UPCR 的描述性趋势
  • 年度随访选取（270–450 天窗口）
  • 无研究方案时只列“未确认候选”，不是终点
  • 课题负责人确认研究方案后，按方案判定终点并记录方案全文
  • 本次实际执行步骤的英文方法学草稿，需研究团队审阅

病种特有化验可录入化验记录；脚本只分析说明中的六张核心表，额外的专病统计需单独编写与验证。

多中心协作

多中心如何协作与合并

身份与成员

  • 每个中心一个项目，设置唯一中心代码（如 BJ01 / SH01 / GZ01）
  • 研究编号在中心内唯一；分析身份 = 项目 + 中心代码 + 研究编号
  • 分中心成员用自己的邮箱注册，由项目负责人按角色添加
  • 保留原始记录编号；冲突会阻止合并，不会自动覆盖

数据协调中心（DCC）合并

  • 各中心在自己的项目中冻结导出
  • DCC 收齐各中心六张核心 CSV，运行合并脚本校验
  • 出现 MERGE_OK 后，再对合并后的数据运行分析
  • 核对输入校验值与人数；合并结果不等同各中心子集结果
流程示例（模拟）：3 个中心的 IgAN 随访研究（BJ01 / SH01 / GZ01）
→ 各中心冻结导出 → DCC 核对与合并 → 描述性分析 → 团队复核；不预设完成时间或研究结果
隐私、权限与留痕

研究编号 · 成员角色 · 冻结数据版本

去标识化

  • 只录入研究编号，不录入姓名、证件号、电话、病案号
  • 研究编号与姓名的对照表由医院保管
  • 编码后的健康记录仍属敏感个人信息，只在批准与授权范围内共享

成员角色与留痕

  • 负责人、录入协作人、分析协作人、只读协作人四种角色
  • 更正须填写原因，修改前后的值、修改人和时间都留痕
  • 随访链接只在生成时显示一次，系统只保存无法还原的校验值

冻结数据版本

  • 冻结同一时刻读取的研究数据，可重新下载同一版本
  • 分析包附带每个文件的 SHA-256 校验值清单
  • 冻结不锁定后续更正，也不替代备份与恢复

数据存放位置

  • 以隐私政策中的说明为准，正在迁至中国境内
  • 迁移完成并公布前，不声明“数据只存放在境内”
  • 机构有境内存储要求时，请在录入真实数据前与我们确认

操作流程

工作台与本地分析

工作台

  • 创建项目：项目名称 + 中心代码 + 病种模块（一个项目对应一个研究队列）
  • 新增患者：研究编号 + 基线日期 + 血肌酐（Scr）+ 尿蛋白/肌酐比值（UPCR）+ 可选病理
  • 随访看板：逾期、即将到期、尚无随访一目了然
  • 录入随访：工作台直接录入，或生成随访链接让患者用手机填写
  • 冻结导出：冻结数据版本 + 数据表 + 分析脚本

本地分析（统计人员）

  • 解压分析包，在包根目录建立独立 Python 环境并安装依赖
  • python analysis/run_analysis.py
  • 有课题负责人确认的研究方案时，加 --protocol 参数
  • 先看运行日志和数据质控清单，再看结果
  • 更正数据后重新冻结导出并复跑，不把旧输出当作本次结果

适合谁使用

四类使用者

课题负责人（PI）

  • 建立单中心或多中心随访队列
  • 按角色管理成员，按研究方案设置随访间隔
  • 数据更正留痕，冻结版本可复核

没有研究护士的主治医生

  • 随访看板提示今天该随访谁
  • 门诊时在工作台直接录入随访
  • 患者也可以用随访链接在手机上自己填写

研究护士 / 临床研究协调员（CRC）

  • 按看板安排随访，录入或发放随访链接
  • 处理数据质控问题，对照原始报告更正
  • 经过简短培训即可掌握日期与单位核对

统计人员 / 数据协调中心

  • 拿到冻结数据版本与可复核的本地脚本
  • 多中心数据合并与校验
  • 评估机构部署时，核验数据流向、备份与运维边界
