共建一个可评估、可复盘的研究起点

建议从一个病种、一个研究问题开始。临床、方法学与医学信息团队共同确定方案，先用模拟数据验证流程，再按审批与授权范围开展真实数据试点。

01 / CLINICAL
临床牵头团队 →确定研究问题、入排标准、结局和随访安排。
02 / METHODS
公共卫生 / 统计团队 →共建分析方案，评估缺失、偏倚和样本可行性。
03 / INFORMATICS
医学信息团队 →核对数据字典、权限边界与部署条件。

拟议90天目标：形成试点方案、字段字典、数据质量报告与继续 / 调整 / 暂停建议；不以论文发表或临床疗效作为试点承诺。

可能适合的中心
  • A 类（核心队列）：有稳定 PD 门诊或住院管理团队，能判断主要结局

  • C 类（增强模块）：可提供 PROM、PET/RKF、容量管理、远程管理数据的中心
